# Shopify Social Gallery Section

An Instagram-style photo gallery section for Shopify **Online Store 2.0** themes. Show customer photos, event photos or user-generated content in a clean square grid, with an optional lightbox.

## Features

- Square image grid, 2–6 columns on desktop and 1–3 on mobile
- Adjustable gap between photos
- Lightbox using the native `<dialog>` element (no libraries)
- Optional caption and link for each photo
- Optional button (for example "Follow us")
- Responsive images with lazy loading, so the page stays fast
- Fully editable in the theme editor

## Install

1. In Shopify admin go to **Online Store → Themes → … → Edit code**.
2. Under **Sections**, click **Add a new section**, name it `social-gallery` and paste the contents of `sections/social-gallery.liquid`.
3. Open **Customize**, click **Add section → Social gallery**, then add photos as blocks.

Works on Dawn and other 2.0 themes.
